- `skinmotion-backend` - Flask-based production backend for soundwave tattoo marker workflows, async media processing, Stripe billing, GCS uploads, and PDF generation.
- `Networks` - Django and DRF backend for auth flows, social graph features, Redis-backed OTP flows, push notifications, and Apple/Google subscription verification.
- `Swigable-ML` - Real-time sip detection system using Python, TensorFlow, Flask-SocketIO, ESP32 sensor data, and a live prediction dashboard.
- `Blocktix` - Django ticketing and resale marketplace backend with Stripe, Web3 workflows, Firebase notifications, wallet features, and QR validation.
- `Mashlife-scraping-project` - Python event aggregation backend using Playwright, BeautifulSoup, geocoding, JSON pipelines, and secured Flask APIs.
- `gridmaster-backend` - Backend contribution within the Yudiz Solutions product ecosystem.
